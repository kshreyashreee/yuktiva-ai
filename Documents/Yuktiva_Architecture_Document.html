Architecture
Overview — Yuktiva AI orchestrates 3–5 specialised AI agents per pipeline via a Node.js/Express backend, streaming results in real-time over Server-Sent Events (SSE) to a React 18 frontend. All agents run on Groq (LLaMA 3.3 70B / 3.1 8B) with smart model routing — large models for complex reasoning, small models for fast transforms — achieving comparable results at ~40% lower cost.

ERROR-HANDLING LOGIC
↯ JSON Parse Failure
Strip markdown fences → JSON.parse → on error: wrap raw text in {_rawText} object. Pipeline continues safely.
↯ GROQ_API_KEY Missing
Pre-pipeline check before agents start → HTTP 500 with actionable message and link to console.groq.com.
↯ File Type Blocked
Multer fileFilter whitelist → HTTP 400 response listing all allowed extensions to the user.
↯ 401 Unauthorized
authMiddleware catches expired JWT → client auto-clears localStorage token and redirects to /login.
↯ Agent API Error
try/catch wraps each agent call → run.status = "failed" → SSE error event emitted to client with message.
↯ Document Parse Failure
fileParser returns {text: "error msg"} and never throws — pipeline context formation continues safely.
